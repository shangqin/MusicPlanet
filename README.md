# 音乐星球

儿童音乐 PWA，使用仓库 `music/` 中的真实音频，零运行依赖，部署到 GitHub Pages。

## 本地使用

需要 Node.js 20 或更新版本。

```sh
npm test
npm run dev
```

打开 http://127.0.0.1:4173 。静态构建运行 `npm run build`，输出在 `dist/`。

## 维护音乐

每个包含歌曲的目录自动成为一个歌单；支持嵌套目录、中文文件名，以及 MP3、M4A、AAC、WAV、OGG、FLAC（实际解码支持取决于浏览器，iOS 建议 MP3/M4A）。目录可放 `cover.jpg`，也支持 PNG、WebP。缺失时使用默认音符封面。

```text
music/
  01_英文儿歌/
    cover.jpg
    01_ABC Song.mp3
    02_Twinkle Twinkle.mp3
  02_睡前音乐/
    01_小星星.mp3
```

数字前缀控制自然排序，显示时隐藏。去掉数字前缀后的目录路径和歌曲名作为收藏身份：调整排序保留收藏，跨目录同名歌曲独立收藏；真正改名或移动目录视为新歌曲。第 60 轮未确认的目录数字排序变化暂按保留收藏实现。身份冲突会使构建失败，避免收藏串联。

GitHub 网页上传/删除或 Mac Git 推送到 `main` 都会触发 `.github/workflows/deploy.yml`，自动测试、扫描、构建、发布。页面重新打开、回到前台或网络恢复时检查曲库更新。收藏仅保存在当前浏览器/设备，没有账号同步。音频按需在线播放，不宣称离线歌曲缓存。

## 播放

播放/暂停、上下首、搜索、歌单筛选、收藏、列表循环、单曲循环、随机播放、音量、进度和 15/30/60 分钟睡眠定时。iOS 音量由系统控制；后台定时依赖系统允许执行 JavaScript 的时机，系统挂起时无法保证精确停止。

使用单一常驻 HTMLAudioElement 和 Media Session API 提供后台播放与系统播放控制。iPhone / iPad 在 Safari 分享菜单选择「添加到主屏幕」。浏览器不会自动播放，首次需要轻点播放。

## 部署

源码和歌曲已获用户明确允许公开。GitHub Pages 使用 GitHub Actions 作为来源。工作流需要 `pages:write`、`id-token:write`。仓库和音频随 GitHub Pages 公开发布。

## 验证边界

自动化测试覆盖排序、曲库扫描、封面与稳定收藏身份。浏览器测试记录见 `TESTING.md`。

**iPhone 和 iPad 真机后台连续播放、锁屏信息、锁屏暂停/切歌仍需实际设备验收，未通过前不视为全部需求验收完成。** 纯 PWA 架构保持不变。
